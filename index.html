À propos

Automatiser tout ce qui peut l'être. Vérifier tout ce qui sera affirmé.

Je m'appelle Captox. Mon terrain : l'I.A., l'open source et les outils qu'on peut faire tourner chez soi. KIWIBYTE est mon laboratoire : chaque vidéo passe par une chaîne de production que j'ai assemblée, du choix du sujet jusqu'au brouillon prêt à publier.

Règle de la maison : aucun chiffre non sourcé. Un script bloque le texte avant la voix si une donnée n'apparaît pas dans les sources. Et la publication reste manuelle : la machine prépare, je décide.

KIWIBYTE

02 Système multi-agents

Un orchestrateur, sept spécialistes

Construit avec Hermes Agent. Tony orchestre ; chaque agent a son profil, son salon Discord et un modèle choisi pour sa tâche, souvent un modèle peu coûteux. Chaque phase écrit son fichier avant la suivante.

Contrôle des faits par script

verifier_idees.py confronte chaque source citée aux données réellement collectées.

lint_script.py bloque un script avant la voix : chiffre absent des sources, phrase trop longue, accroche de plus de 14 mots.

03 Voix

VoiceStudio, la voix clonée en local

Les voix off sont générées sur ma machine avec VoiceStudio, une application open source (AGPL-3.0) de clonage vocal, appelée par son API locale.

Le texte est synthétisé phrase par phrase, puis réassemblé avec des silences calibrés. Chaque scène reçoit un fichier de minutage pour caler les animations sur la voix.

04 Veille

Le Top 10 GitHub, chaque matin

Un collecteur lit les tendances réelles (GitHub Trending et API GitHub, Hacker News, Hugging Face, arXiv, Lobsters, dev.to) et garde l'URL et la date de lecture de chaque valeur. La veille tourne seule à 7 h.

veille

$ python veille_collect.py
# GitHub, Hacker News, Hugging Face, arXiv…
$ python veille_top10.py
# classement = étoiles gagnées sur la période,
# jamais de mémoire
$ python verifier_idees.py <date>

  sont confirmées
